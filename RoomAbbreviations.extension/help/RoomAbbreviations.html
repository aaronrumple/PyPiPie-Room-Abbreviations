Room Abbreviations

Keeps the Room Abbreviation parameter on every room filled in from a room-name → abbreviation table stored inside the project. Rename a room and its abbreviation updates by itself.

Quick start

  1. Open the project and click Setup.
  2. Leave Load the standard abbreviations selected (or pick a custom file) and click Run Setup. Tick Open the standard room tag if you need your own tag.
  3. Read the report. Room names listed under Room names not in the table have no abbreviation yet.
  4. Click Edit Abbreviations, then Add room names from project, fill in the missing abbreviations and Save.
  5. Tag rooms with a tag that shows the abbreviation. From now on, renaming a room updates it.

Setup

Setup opens one dialog with three parts, then fills every room and opens a report.

Room Abbreviation parameter

Shows which parameter Rooms use, or that the standard one will be added (see The parameter). Nothing to choose here.

Standard and custom are either/or. If the project already has a table, choose Replace (use only the new list) or Merge (keep existing entries; the new list wins where names match).

Room tag

Tick Open the standard room tag to create a new tag to start your own tag from the office standard. After the rooms are filled in you'll see a dialog explaining the steps, then choose where to save your copy and it opens in the Family Editor. See Room tags.

Run Setup again whenever you want to change the table.

Edit Abbreviations

A grid of the project's table. The Rooms column shows how many rooms in the project use each name; 0 means the name is listed for future use. Nothing changes in the project until you click Save.

Rules

  • Names match ignoring upper/lower case and extra spaces: Mech  Room = MECH ROOM.
  • A name can only be listed once. Duplicates are shown under the grid and must be fixed before saving.
  • Leave the abbreviation blank for rooms that don't have one.
  • Cancel only asks to discard if names or abbreviations changed; checking boxes isn't a change.

Update All Rooms

Re-applies the table to every room and opens a report: rooms updated, rooms listed without an abbreviation, room names not in the table, and rooms that couldn't be edited. Use it after the project was edited on a computer without pyRevit, after syncing with central, or just for the report.

Room tags

There are two ways to make a tag that shows the abbreviation. Both show a dialog with these steps before anything opens, and both have a Help button.

Start fromWhere
A copy of the standard Room Tag - AbbreviationSetup > Room tag > Open the standard room tag to create a new tag
Revit's blank Room Tag templateNew Room Tag Family button

From the standard tag

  1. Choose a name and folder for your copy. The standard that ships with the app is never changed.
  2. The copy opens in the Family Editor. The Room Abbreviation label is already set up; select a label and click Edit Label to change what it shows.
  3. Change text types, sizes and linework as needed.
  4. Save, then Load into Project. The family takes its name from the file, so a new file name keeps the standard tag in your projects unchanged.

From a blank template

  1. Pick a Room Tag template (if Revit has more than one).
  2. Choose a name and folder. The family opens in the Family Editor.
  3. Create > Label and click in the view.
  4. In Edit Label, click Add Parameter (bottom left), Select…, group Rooms, Room Abbreviation, OK, then move it into Label Parameters. Add Name, Number, etc.
  5. Save, then Load into Project.

Shared parameter file

Edit Label only lists parameters from Revit's active shared parameter file. If you use your own file, you're asked to either add Room Abbreviation to it (changes nothing else) or switch Revit to the Room Abbreviations file; the report says how to switch back.

Rooms without an abbreviation show nothing, so give the abbreviation its own label rather than combining it with Name, to avoid a blank line or stray separator.

The tag uses the same parameter as the open project. If the project's Room Abbreviation is a project parameter (not shared), tags can't show it and you are warned.

Automatic updates

While pyRevit is loaded, placing a room or changing its Name (Properties, a schedule, or a tag) writes the abbreviation straight away, inside the same undo step.

  • Names not in the table, or listed with a blank abbreviation, get an empty abbreviation. This also clears an old abbreviation after a rename.
  • Typing an abbreviation by hand works, but it is replaced the next time the room is renamed. Change the table instead.
  • Projects where Rooms have no Room Abbreviation parameter are ignored.
  • Changing the table doesn't touch rooms until you save with Update all rooms ticked or run Update All Rooms.

File format

Plain text, one room per line, room name and abbreviation separated by a tab:

Room Name	Abbreviation
OFFICE	OFF
MECHANICAL	MECH
VESTIBULE
  • The header row is optional. Lines starting with # are ignored.
  • A blank second column means "no abbreviation".
  • From Excel: Save As > Text (Tab delimited) or Unicode Text. Both work.
  • If a name appears twice, the last one wins and you are told.

Office standards

The standards folder in the extension holds what Setup's standard options load:

FileUsed for
Standard Room Abbreviations.txtLoad standard abbreviations
Room Tag - Abbreviation.rfaStarting point for Open the standard room tag (a copy is opened, never the file itself)

To change the office standard, replace a file and keep its name. Projects already set up keep their own table until Setup is run again.

The parameter

Room Abbreviation is a text, instance, shared parameter on Rooms in Identity Data (GUID 7dcd381d-1775-4033-926e-13705844273d, group Rooms). It is the same parameter the PyPiPie / Data Pusher Room tools use, so both work together.

If a project already has a Room Abbreviation on Rooms, that one is used, even if it has another GUID or is a project parameter. If one exists but isn't on Rooms, Rooms is added to it. A new one is created only when none exists.

The table itself is saved in the project (extensible storage), so it travels with the file and with Save As. It is not linked between projects; use Export / Import to copy it.

Workshared models

  • The table is one element. Saving it needs that element to be free; if someone else has it, sync and try again.
  • Rooms owned by someone else, or out of date with central, are skipped and listed in the report. Run Update All Rooms after they sync.
  • Automatic updates only change rooms you are already editing.
